# MinPJ Frontend

Modern Todo List application frontend built with React.

## Technologies

- React
- JavaScript
- HTML5
- CSS3
- Axios
- React Router

## Requirements

- Node.js
- npm

## Installation

1. Clone the repository:

```bash
git clone https://github.com/walid-elmoussaoui/minpj-frontend.git
```

2. Navigate to the project:

```bash
cd "frent end"
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

## Backend

This frontend connects to a Laravel REST API backend.

## Security

Never commit `.env` files or sensitive API credentials.
